# موجز | MOUJAZ Web V1 — Prototype

واجهة تجريبية لموقع موجز مبنية بـ Next.js 15 وReact وTypeScript، RTL ومتجاوبة.

## التشغيل
1. ثبّت Node.js 20.9 أو أحدث.
2. افتح المجلد في VS Code.
3. شغّل `npm install`.
4. شغّل `npm run dev`.
5. افتح `http://localhost:3000`.

## ما يعمل حالياً
- الرئيسية، الأدوات، الخدمات، نموذج الخدمة، مراجعة الطلب، النجاح، طلباتي، الحساب، القائمة والفوتر.
- حساب سعر التقرير والصفحات الإضافية والتسليم السريع، وسعر عروض 2D.
- إيقاف تنسيق بحوث التخرج وعروض 3D من قائمة الخدمات في `app/page.tsx` (`active:false`). لتفعيلهما مستقبلاً، غير `active` إلى `true` بعد تنفيذ نموذج تسعيرهما.
- حفظ طلبات تجريبية محلياً في `localStorage` على نفس المتصفح فقط.
- فتح حساب الدعم `https://t.me/MoujazSupport`، ونسخ رسالة الطلب.
- رابط فاحص التقارير الحالي.

## ما لا يعمل بعد — مهم
- **لا يوجد تسجيل دخول Google فعلي**؛ زر Google معطّل حتى ربط Supabase Auth.
- **لا توجد قاعدة بيانات أو لوحة إدارة**؛ الطلبات لا تصل إلى موجز، ولا تنتقل بين الأجهزة. لا تستخدم هذه النسخة لاستقبال طلبات حقيقية.
- حالات الطلب لا تُحدَّث من إدارة، والتسليم النهائي سيكون عبر تيليجرام عند تفعيل النظام.
- مولّد الأسئلة يحتاج API ومراقبة استخدام.
- كود الخصم تجريبي فقط؛ لا توجد كوبونات فعالة.
- لا يوجد رفع ملفات بعد. يفضّل إضافة رفع مرفقات آمن أو إرسالها عبر تيليجرام قبل الإطلاق.
- بيانات الطلبات المخزنة في المتصفح ليست تخزيناً آمناً للإنتاج.
- شعار موجز الحالي تمثيل نصي مؤقت؛ استبدله بملف الشعار المعتمد عند توفره.
- أُرفقت الخلفية السينمائية العمودية المتاحة في `public/hero-mobile.png`؛ يستخدم سطح المكتب قصّاً متجاوباً منها مؤقتاً إلى حين توفير النسخة الأفقية المستقلة.
- خط IBM Plex Sans Arabic يُحمّل من Google Fonts ويحتاج إنترنت. يمكن تضمينه محلياً لاحقاً.

## الخطوة التالية
إعداد Supabase + قواعد الوصول RLS، وربط تسجيل Google والطلبات الآمنة، ثم لوحة الإدارة والدفع اليدوي، ثم الاختبار والنشر.
